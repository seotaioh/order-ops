# Automation 중단 조건 (Lab 19)

자동 실행은 아래 다섯 조건 중 하나라도 참이면 **그 자리에서 멈추고** 상태를 보존한 뒤 알린다. 멈춤은 실패가 아니라 사람에게 넘기는 정상 경로다.

| # | 중단 조건 | 감지 신호 | 보존할 상태 | 알림 (수신자 · 포함 정보) | 재개 주체 | 재시도 상한 |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | **반복 실패** — 같은 입력으로 같은 단계가 다시 실패 | 같은 커밋 SHA·같은 명령에서 종료 코드 ≠ 0이 **2회** 연속. 실패 원문의 첫 줄이 직전과 같음 | 실패한 명령의 전체 출력, 커밋 SHA, 작업 트리를 **그대로**(되돌리지 않음), 마지막 통과 커밋 | 저장소 소유자 · 명령, 종료 코드, 출력 첫 30줄, 직전 통과 SHA | 사람이 원인을 보고 재실행 지시 | 자동 재시도 **1회**(총 2회 실행). 그 뒤 중단 |
| 2 | **범위 확장** — 승인된 계획·Issue Scope 밖을 건드려야 완료되는 상황 | 변경 파일 집합이 허용 집합을 벗어남, 또는 완료 조건을 만족시키려면 Out of Scope 항목 수정이 필요하다고 판단됨 | 허용 집합 밖 변경은 **적용하지 않고** diff를 `notes/automation/pending-<SHA>.patch`로 저장. 작업 트리는 허용 범위 변경만 남김 | 저장소 소유자 · 범위 밖 파일 목록, 왜 필요한지 한 줄, patch 경로 | 사람이 범위 승인 또는 거부. 승인 시 계획 파일 갱신 뒤 재개 | 재시도 없음 |
| 3 | **권한 부족** — 읽기 전용 밖의 행동이나 접근 거부 | 명령이 권한 오류(403, `permission denied`, `gh` 인증 실패)를 돌려줌, 또는 다음 단계가 커밋·푸시·코멘트·라벨·머지·`npm install`처럼 외부 변경이나 설치를 요구함 | 그때까지의 보고서 초안(`notes/automation/runs/<날짜>-draft.md`), 실행 로그 | 저장소 소유자 · 필요한 권한·행동, 그것이 필요한 이유, 사람이 대신 할 명령 | 사람이 직접 수행하거나 권한 부여 뒤 재개. 자동화가 권한을 스스로 넓히지 않는다 | 재시도 없음 |
| 4 | **데이터 부족** — 판정에 필요한 입력이 없거나 불완전 | 계획 파일 없음, Issue 본문에 템플릿 절 없음, 재현 절차가 재현되지 않음, 정책 문서 절 제목 파싱 실패, 비교 기준 커밋 없음 | 무엇이 없었는지 적은 보고서, 추정으로 채운 값 **없음**(빈칸 유지) | 담당자(Issue 작성자 또는 소유자) · 빠진 입력 목록, 어디서 가져올 수 있는지 | 사람이 입력을 채운 뒤 같은 프롬프트로 재개 | 재시도 없음(입력이 바뀌기 전에는 결과가 같다) |
| 5 | **외부 상태 변경** — 실행 중 대상이 바뀜 | 실행 시작 시 기록한 head SHA와 끝날 때의 SHA가 다름, PR이 닫히거나 머지됨, Issue가 닫힘, 작업 트리에 자동화가 만들지 않은 변경이 생김 | 시작 시점 SHA 기준 결과에 「대상 변경됨」 표시, 작업 트리의 외부 변경은 건드리지 않음 | 저장소 소유자 · 시작 SHA, 현재 SHA, 바뀐 것, 결과가 어느 SHA 기준인지 | 사람이 새 SHA로 재실행 지시 | 새 SHA로 자동 재실행 **1회**까지. 그 안에 또 바뀌면 중단 |

## 공통 규칙

- 어떤 조건에서도 **무한 재시도는 없다**. 상한은 표의 마지막 열이며, 상한을 넘으면 중단으로 전환한다.
- 멈춘 뒤 작업 트리는 자동화가 만든 변경과 외부 변경을 구분할 수 있어야 한다. 자동화는 되돌리기(`git checkout --`, `reset`)를 하지 않고, 자기 산출물은 `notes/automation/` 아래에만 쓴다.
- 보고서에는 항상 「어디까지 했는지 / 왜 멈췄는지 / 무엇이 있어야 재개되는지」 세 줄이 맨 위에 온다(`notes/task-boundary.md` 멈춤 조건 형식과 같다).
- 알림에는 비밀값(토큰·키·접속문자열)을 넣지 않는다. 매치가 있으면 파일·줄 번호만 적는다.
- 사람이 재개하기 전에 자동화가 같은 작업을 다시 시작하지 않는다(예약 주기가 돌아와도 미해결 중단이 있으면 건너뛰고 「미해결 중단 있음」만 알린다).
